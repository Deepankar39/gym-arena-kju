# Gym Arena – KJU Java DSA

These programs are standalone Java implementations for the DSA practical syllabus. They do not require Tomcat, Node.js, Express or MySQL.

## Compile all

```powershell
javac *.java
```

## Phase 1

```powershell
java MemberManagement_LinkedList
java Registration_LinkedList
java GymAction_Stack
java EquipmentWaitlist_Queue
java MembershipFeeExpression_Stack
```
